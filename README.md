# borshevik-tecla

This repository provides a Fedora-compatible RPM packaging of the [GNOME Tecla](https://gitlab.gnome.org/GNOME/tecla) library.

Tecla is a fuzzy keyboard layout search helper library used by components such as GNOME Control Center and GNOME Initial Setup. It is a required dependency starting from GNOME 48.

## 📦 Package details

- **Package name:** `tecla`
- **Version:** 48.0.2
- **Spec file:** `tecla.spec`
- **Source:** https://download.gnome.org/sources/tecla/48/tecla-48.0.2.tar.xz

## 🚀 COPR Usage

This package is used as a build-time dependency for [borshevik-control-center](https://github.com/komorebithrowsatable/borshevik-control-center) and distributed through Fedora COPR.
